# LESSON 6 : SUMMARY

## What I learnt:

1. Boolean values : true and false.

2. if-statements.

3. Comparison operators : <, >, ===, <==, >==, !==.

4. Logical operators : &&, ||, !.

5. Introduction to algorithms and the creation of Rock-Paper-Scissor game to demostrate it.

6. Truthy and falsy values. Falsy values are: 0, false, null, undefined and Nan.

7. Shortcut for if-statement: ternary, guard and default operators.

8. How guard and default operators can be used to short-circuit an execution.
