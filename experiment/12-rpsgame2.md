### GOAL:

Create a rock-paper-scissor game, which:

- allows users to click an option among rock, paper and scissors.
- allows the computer to select a random pick.
- compares the two picks according to these rules:
  1.  Rock beats scissors.
  2.  Scissors beat paper.
  3.  Paper beats rock.
- Show the result.
- Update the scores.
- Reset the scores.
- Autoplay.

### Initial UI Flow:

- User picks.
- Score.
- Reset.
- Auto-play.

### UI: Active Session:

- Computer pick.
- Result.
